# ACP 遗留收尾与 GenUI 有界优化

本轮基线为 `7d955c8b78e4ccd5cb33b0a193cffc6f2adaa25b`。实现提交为 `7e0f402`，审阅修正为 `00859bd`。生产方向保持 Go 文档核心、AGY ACP + Gemini 3.8 Flash、A2UI 1.0、现有 Catalog 与 React Renderer。

决定采用**一个空闲进程缓存，每次生成新建独立 Session**。缓存稳定降低连接准备代价；本轮完整生成时间没有证明整体加速。原文权威、捕获文本/路径/版本、页面深层校验、原子视图提交和 Undo 保护继续作为提交条件。没有新增生产 Jev、持久 ViewPlan/EvidenceIndex、通用 Provider 平台或另一套渲染器。

## ACP 逐项状态

| 审计项 | 当前状态与证据 |
|---|---|
| `initialize` 身份与协议 | 基线已报告客户端身份并核对协议。本轮进一步保留真实 `agentInfo`、capabilities、`authMethods` 和完整应答；冷进程真实握手，热连接使用有进程身份绑定的缓存答案。 |
| Prompt 取消误等进程退出 | 删除 `cancelGracefully` 的固定 2 秒退出等待。等待的是 Prompt turn 应答；1 秒内未应答则有界杀死并丢弃进程。先复现 2.008 秒失败，确认应答的回归修复后为 0.17 秒。 |
| pending / 稀疏工具更新 / `other` | 按 toolCallId 合并类型、路径与状态；信息不全的观测可以后续补全。明确越界路径（包括没有 kind 的通知）及 execute 等不支持操作仍中止；权限批准继续采用原类型、路径、符号链接规则。 |
| 实际模型确认 | 接收 Session 配置与后续更新。服务端报告值与请求不同则拒绝提交；没有确认值时不把请求值写成实际模型。模型列表仍来自已有 Session 握手缓存。 |
| 思考级别确认 | 本轮 ReadBench 实际设置 `thought_level=low`，只使用服务端提供的 configId/选项，并记录确认值。常规界面未新增思考级别控件。 |
| 短命进程与连接代价 | 新增应用拥有的单空闲进程缓存；每次独占借用、新建 Session 和任务目录，Session 关闭获确认后才可复用。不复用对话。 |
| 进程异常、并发、空闲与退出 | 默认空闲两分钟退出；命令或环境改变不复用。并发文档可使用独立临时进程，结束后最多保留一个空闲进程。不确定状态丢弃、不自动重试。宿主退出清理缓存和私有目录。 |
| 原有隔离及提交保护 | 规范路径、符号链接检查、来源快照、深层校验与视图/Undo 原子提交保持。AGY 自身的权限设置仍决定其沙箱能力，通知检查不被描述为 OS 沙箱。 |

缓存进程的工作目录为稳定的私有 `markgogo-acp-*`，Session 工作目录为每次独立的 `markgogo-genui-*`；显式冷连接对照的六个一次性进程则直接使用本次 Session 目录作为进程工作目录。空或重复返回上次 Session ID 会使该进程丢弃。迟到的其他 Session 通知不会进入当前任务；其权限请求返回 cancelled。每个物理进程只有一个退出监听。

## 真实冷连接与复用对照

使用原 ReadBench 三题 `d06-t1`、`d04-t2`、`d12-t2`，两种策略各重复两次，共 12 次初始生成。顺序为 cold-r1 → reuse-r1 → reuse-r2 → cold-r2；所有原文、请求和格式逐题相同。全部实际模型均为服务端确认的 `gemini-3.8-flash`，思考级别均确认为 `low`。

冷策略通过已有构建钩子设置 `freshAgent`，其他输入不变。复用策略包含第一次冷启动，不剔除该次较长结果。因此物理冷连接共 7 次、实际热连接 5 次。12 个 Session ID、任务目录和输入副本目录均不同。

| 任务 | 冷策略完整生成均值 | 复用策略完整生成均值 | 冷策略首次有用内容上界均值 | 复用策略首次有用内容上界均值 |
|---|---:|---:|---:|---:|
| 测试统计 `d06-t1` | 15.120 s | 20.902 s | 18.184 s（n=2） | 25.955 s（n=2） |
| 路由与别名 `d04-t2` | 16.065 s | 22.162 s | 19.590 s（n=1） | 25.085 s（n=2） |
| 文档与实现差异 `d12-t2` | 17.963 s | 21.956 s | 21.230 s（n=2） | 25.186 s（n=2） |
| 合计 | 16.383 s（n=6） | 21.673 s（n=6） | 19.683 s（n=5） | 25.409 s（n=6） |

完整生成计时为 Go `run.end.elapsedMs`，包含设置、模型/工具往返、候选校验及提交；不含随后阅读探测。首次有用内容是经逐事实审阅确认的真实 WebView 首次采样上界，不能当作精确首帧时间。缺失的观测保持 null。

实际冷连接与热连接的**设置阶段**均值为 **3.347 s → 0.974 s**，约减少 2.37 秒。真实 `session/new` 为冷约 2.80–4.26 s、热约 0.75–1.40 s；这与前置无生成连接探测的 3.16–3.51 s / 0.25–0.70 s 是不同测量场景，均不支持原审计的“热 Session 4 ms”。`initialize` 约 46–54 ms；模型/思考设置每次约 0.6–15.4 ms；热连接 `session/close` 约 0.09–0.14 ms。提交前校验为 1.15–41.83 ms。

本轮复用策略完整耗时反而更高，差异集中在 LLM/工具阶段（策略均值 20.298 s 对 12.990 s）。这组小样本不能判定该差异的因果，不能自动归因于随机波动，也不能据准备阶段缩短宣传整体加速。缓存保留的依据是已经重复测得的连接准备收益和受限的生命周期，而非尚未证实的总耗时收益。

上一轮 GenUI 优化最终六次均值为 21.961 s，本轮复用策略为 21.673 s，差约 1.3%；它们是分时历史批次，不是单因素因果对照。前轮结果仍见 [GenUI 优化报告](genui-optimization.md)。

## 内容、来源与真实阅读

12 次共 44 项必要事实检查：44 完整支持、0 部分支持、0 不支持。每种策略各 22 项；前轮六次为 21 完整、1 部分。本轮只替换一条通用保真规则，要求翻译中保留原文技术术语；没有 `deepest prefix` 专用词典或生成结果修补。

四次路由答案均保留 if/else 优先级、`deepest prefix`、canonicalPath、`/tmp` 与 `/private/tmp`、documentId；未再出现“最长公共前缀”。一份使用“最长前缀（deepest prefix）”，结合包含关系及原词仍表达同一规则。三次提交的测试文件数/项数全部准确；长文四次均保留八类差异及日期、404、版本和 API 大小写，React 行仍保留“功能上可用”的限定。没有新增题外审计或虚构官方 Issue。

测试统计保持单张三行 ComparisonTable，路由保持三阶段 Timeline 与别名说明，长文保持单张八行比较表。来源标题、occurrence 与章节哈希可解析并支持内容。原始 11 份即时观测执行 44 项通用阅读探测：19 PASS、0 FAIL、25 UNSUPPORTED；原文和视图字节保持、视图模式恢复。题目未要求且没有生成的 Tabs/折叠控件不作为事实失败。

其中 `d04-t2-ACP-cold-r2-20261110113207-5404f4` 的 Go 校验和提交成功，但原观测器在旧文档仍活动时立即返回“目标文档面板不存在”，未等待，故原记录是 FAIL 且没有首次内容采样。修正既有观测器，在正确窗口激活捕获的 documentId 并有界等待该面板后，同一已提交视图补观测通过；未重新生成该答案，`render.initial.json`、初始截图、原 FAIL 和 TTU 缺口均保留。该次四项内容事实来自不可变产物审阅，不冒充原始页面观测。

上述是 AI 辅助原文审阅与父任务整合，不是独立人类双标或阅读速度实验。评分器的完整多轮任务分母仍保留：本次 `initialOnly` 没有执行 d04 的三个后续回合，不能把初始视图通过写成整个四轮任务通过。

## 生命周期与最终修正版验证

真实应用另执行五步：A 整份重生成；A 生成时激活 B 并修改全局模型后取消 A；生成 B 时切换 A 再返回；只杀死该次 AGY PID 模拟崩溃；显式重生成 A 恢复。全部生成仍请求并确认为 Gemini 3.8 Flash，替代模型只用于设置隔离测试，没有在该模型上生成。

- 取消时 A/B 的原文和视图字节均保持；A 已有的 Undo 也保持，B 原本没有 Undo，取消后仍不存在。Go 文档生成状态恢复。真实 AGY 没在 1 秒宽限内应答，`session/cancel → run.end` 为 1.015 s，因此丢弃旧进程，下一次按需启动新进程；这不计作“确认取消后热复用成功”。确认取消后复用由独立回归覆盖。
- 首版临时脚本把 `run.end.data` 当成完整事件读取时间，并错误地把自动化消息队列 idle 当作任务结束；已保留原报告，改用原始完整 wire 事件离线重算。原始采样未分别记录 promise 完成和 `generating=false` 的时间，UI 精确恢复时间保持未知，不采用错误的 1 ms 数字。
- 崩溃后旧视图与 Undo 均保留，显式重生成使用新 PID、新 Session 和目录并实际渲染；其他文档未被覆盖。
- 审阅修正提交 `00859bd` 后另建原生副本，同三题再次 smoke：3/3 真实生成、服务端配置确认、提交与渲染通过；阅读探测 5 PASS、0 FAIL、7 UNSUPPORTED。这三次不替换或混入上述 12 次性能分母。
- 最终副本的 8 个运行时文件 SHA-256 与工作树一致。退出前采样确认 AGY PID 55573 存活；正常原生 Quit 后应用 PID 55457 和该 AGY 均不存在，缓存目录已删除，监督进程退出码为 0。

## 代码、依赖与维护代价

相对本轮基线，运行时代码增加 1,034 行、删除 128 行，净增 906 行（含空行和注释）；其中新缓存文件 335 行。测试增加 1,193 行、删除 37 行。代价来自生命周期、稀疏通知、服务端确认及相应边界，不能称为“零维护成本”。没有新增生产 Go/npm 依赖，没有新增持久格式、公开绑定或后台服务。

缓存最多保留一个空闲 AGY 主进程；最终单次 RSS 采样为 278,272 KiB，约 272 MiB，不是完整进程树的内存总量。默认两分钟空闲退出；并发文档可临时拥有额外进程。关闭必须同时管理任务、Session、进程和私有目录。
