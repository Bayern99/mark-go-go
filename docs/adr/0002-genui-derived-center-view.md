# ADR 0002：GenUI 是只读的派生视图模式，视图文件用 A2UI 1.0

- 状态：已采纳（2026-11-06 设计评审；实现前待 A2UI 1.0 在 MyGo 窗口内的最小渲染验证）
- 取代：ADR 0001 D4 中“GenUI 使用内部小型 schema；A2UI v1.0 协议暂不采用”

GenUI 原本做成右侧栏，只有 3 种卡片，按章节平铺。它不符合 brief 里“替代视图”的定位，看上去像一个附属小工具。现在把它改成窗口中央的一种视图模式（Preview / Markdown / GenUI）。GenUI 视图从原文派生，只读，不写原文；修改和批注都落在原文上。这样不会出现“一个文件两个版本”，也就不需要双向同步和合并。视图文件采用开放标准 A2UI 1.0，因为它是 app 与所有外部 Agent 之间的接口，渲染器可以替换，接口格式不能随便换。

## 决定

- **原文是唯一主体。** 数据只有一个方向：原文 → GenUI 视图。视图随时可以删掉、重新生成，删了也不丢内容。GenUI 不写原文。修改原文只有三条路：预览、Markdown，以及以后 ADR 0001 D5 的修改建议。
- **修改走跳转。** GenUI 里每个组件都有“去原文修改”：切到预览，选中来源处的原文；改完回到 GenUI 时，恢复原来的滚动位置。
- **批注写进原文。** 批注是放在被批注块后面的 HTML 注释：`<!-- note: … -->`。`note` 后面以后可以加属性（作者、id、已解决），app 遇到不认识的属性要原样保留。判断“原文已改”时不算批注块。在 GenUI 组件上加的批注，落到它来源引用的那一块原文后面，不细到摘要里的某一句。
- **渲染位置。** 用 React 在同一个 WebView 页面里渲染，不用 MyGo 原生 UI。
- **视图文件。** 隐藏的同级文件 `.<name>.md.genui.json`，`version: 2`。外层放我们自己的字段：`generatedAt`、`model`、`request`（用户写的生成要求）、`sources`（来源引用表：heading、occurrence、fnv1a32 哈希）。`a2ui` 字段里是 A2UI 1.0 消息。组件用 `sources: [id…]` 引用来源表。v1 文件不迁移，只提示“这是旧版视图，请重新生成”。
- **组件目录。** 布局直接用 A2UI 基础目录：Column、Row、Tabs、Card、Text。另做 5 个高级组件，每个自己负责排版质量：KeyPoints、MetricGrid、ComparisonTable、Timeline、Checklist（只读）。AI 只负责选组件、填内容、排顺序，不生成 HTML，也不生成 JS。
- **交互。** 只有视图内的本地状态（标签页、展开、排序、筛选），再加一个 app 动作：跳回原文。
- **重新生成。** 默认只换掉标着“原文已改”的组件（A2UI `updateComponents`），其他组件和布局保持不变；也可以选“全部重新生成”。每次生成前保留上一份视图，可以撤回一次。
- **生成过程。** 生成中显示进度和骨架，完成后整份显示。以后要做流式，不需要改格式。
- **Go 端** 只传字节，保留 1 MiB 上限；组件与消息的校验只有页面那一套规则（`Catalog` + `MessageProcessor`），Go 在写入前调用它并按结论提交，不复制组件规则。

## 2026-11-10 重评：保留渲染契约，按证据改善生成

保留 `version: 2`、A2UI 1.0、现有 Catalog、React 与组件内的本地交互状态。生成器的选择器、规划提示或推理格式不成为新的权威文档，也不要求换 Renderer。来源 ID、引用支持、精确定位和任务事实覆盖分别评价：父节引用包含子节，不能把缺少子节独立 ID 判为内容遗漏。

下一步先复用 `SourceStore.target(ids, text)`、现有精确引语与 `replaceIds` 合并；只有真实任务证明现有来源表达或跨轮目标不足，才增加最小字段或持久计划。当前规划提示对照尚不能证明需要独立 ViewPlan 运行时；本轮未引入新视图格式、通用插件平台或文档图谱。以 [ReadBench](../research/readbench/execution-contract.md) 的真实应用、引用、交互与更新证据作为变更门槛。

本轮真实 AGY 产物曾把 Tabs 放进不允许它的 Card，宿主已提交后页面才显示 `UNALLOWED_CHILD`。现已复用页面现有深层校验器，把候选校验前移为原子提交条件：宿主把**将被写入的完整候选**（已盖元数据与来源哈希，局部更新则是与当前视图合并后的整份历史，含末尾换行）作为单个字符串参数交给页面导出的 `validateGeneratedView`，通过后才写视图与 Undo 备份；页面拒绝、桥缺失、页面不可用或取消都保留上一份有效视图与备份，并按普通 `invalid-output` 报告。不在 Go 复制第二套组件规则，也没有新增 IPC 或格式字段。整份 `createSurface` 仍拒绝孤儿组件；含 `updateComponents` 历史时允许被替换容器退休下来的旧子组件，因为 A2UI 没有删除组件。

## 放弃的方案

| 方案 | 放弃原因 |
|---|---|
| 把 GenUI 写进 `.md`（```genui 块、MDX、directive） | 等于让 GenUI 改写原文，会污染原文在其他编辑器里的显示；Crepe 代码块预览走 innerHTML，挂不上 React；MDX 会执行代码 |
| 在 GenUI 里原地编辑 | 等于再做一个编辑器，而且要反向同步 |
| 批注放在旁挂文件 | 要另写 Go 写入路径和多层锚定；只分享 `.md` 时批注会悄悄丢失；对摘要句做锚定会锚错（Hypothesis #7571） |
| CriticMarkup | 大多数编辑器会原样显示 `{>>`；没有可用的 remark 实现 |
| MyGo 原生 UI 渲染 | 原生窗口里没有页面，必须重排窗口结构；没有数据驱动 UI，要自己写解释器；组件目录要维护两份；二进制大约多 0.9–1.3 MB |
| json-render 0.22 | 单一厂商的格式，不约束嵌套；体积更小（15.9 KB gz，A2UI 是 76.9 KB），但这点不是决定因素 |
| CopilotKit / AG-UI / Thesys / MCP Apps | 分别需要它们的 runtime 或后端、只是协议不是渲染器、需要 API key、渲染任意 HTML |

## 后果与风险

- `@a2ui/react` 0.15 还在 1.0 之前，近几个小版本都有破坏性变更。对策：`@a2ui/*` 精确锁版本，只通过一个适配文件接入，组件目录 schema 自己维护一份。
- 新增依赖 `zod` 3 和 `markdown-it`。
- 这些改动会影响 #6 已交付的格式与面板、#5 和 #7 的规格（Generate 按钮的位置、Agent 的输出格式）、以及 `docs/interfaces.md`。
