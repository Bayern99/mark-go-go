# ADR 0005：工作区、文档标签与窗口归属

- 状态：已采纳；2026-11-17 修订为单窗口多工作区。
- 原采纳日期：2026-11-08
- 补充：ADR 0001 的多窗口／标签页模型未决项，以及 ADR 0004 的工作区导航职责。

原决策把一个文件夹、一个 Workspace 和一个原生窗口绑定在一起。多文档组落地后，同一 Workspace 的标签、保存和恢复已经可靠，但从 Finder 打开另一文件夹的原文仍会创建新窗口；高频跨文件夹编辑因此变成 macOS 窗口管理。本次只修订窗口归属，不改变文档、编辑器或 GenUI 契约。

## 已确认的产品决策

1. **一个原生窗口默认承载多个 Workspace。** Workspace 仍是一个文件夹根目录及其导航范围；窗口不再是根目录的身份。窗口顶部只有一组跨 Workspace 的文档标签，不增加第二层 Workspace 标签。
2. **左栏仍只显示一个 Workspace 的文件树与过滤。** 原 Workspace 名称就是切换菜单：列出本窗口已打开的根目录，并提供 `Open Folder…` 与 `Close Workspace`。选择根目录只更换左栏导航，不重建文档面板。
3. **最近文档往返复用文档标签。** 可见标签直接点击；溢出标签继续进入可搜索菜单，并按最近使用优先排列。`Ctrl+Tab` 在当前文档与最近的另一份文档之间往返，包括目标位于溢出菜单或其他 Workspace 时。
4. **同一份磁盘文件全应用只保留一个编辑会话。** 从 Finder、菜单或文件树重复打开时定位并激活已有标签。路径相等、规范化路径与 `os.SameFile` 仍共同判断；MyGo 自己完成的 duplicate-open focus 也同步到页面，不允许原生标题与页面选中不同文档。
5. **打开文件先复用当前窗口。** 先定位已有文档；否则进入包含该文件的最深已打开根目录；没有匹配根目录时，在当前窗口加入文件父目录。只有应用没有可复用窗口时才创建原生窗口。
6. **空 Workspace 不隐藏或关闭其他文档。** 关闭根目录的最后一个标签保留该根目录，中央显示其空状态；其他根目录的标签仍在。选择空根目录后，原生 File/Edit 命令不得作用于之前属于其他根目录的隐藏文档。
7. **关闭文档与关闭 Workspace 是不同范围。** `⌘W` 关闭当前文档；Workspace 菜单的 `Close Workspace` 只确认并关闭该根目录的标签，再移除导航，其他根目录不动。取消保留该根目录及全部标签。关闭最后一个根目录后，原窗口显示 Welcome。原生窗口关闭按钮仍确认并关闭整个窗口的文档组。
8. **首次保存与另存为只迁移文档归属。** 文档保留 `documentId`、内容、版本、视图跟随与生成槽；按同一路由进入目标根目录，但不因此新建另一个原生窗口。目标已是另一份打开的文档时仍拒绝写入。
9. **切换文档不改变既有编辑与生成行为。** 非活动 `DocumentPane` 保持挂载，编辑内容、视图模式、光标、滚动与阅读状态继续由原机制保留；生成任务仍属于发起它的原文。
10. **重启恢复一个窗口中的多个根目录。** 沿用现有 `session.json` 的根目录、标签顺序、活动文档与视图模式；每个根目录增加可选 `active` 标记，记录窗口退出时选择哪个导航。旧会话没有该标记也能读取。恢复时合并旧的多个窗口记录，不再按根目录重建多个原生窗口。
11. **文件导航只包含 Markdown。** 沿用 `index.go` 的 `.md` / `.markdown` 过滤、必要文件夹层级、增量索引与标题/摘要搜索；不为大量文件引入另一套标签或分类系统。
12. **MyGo 文档组增加受控的子集关闭。** 除整窗口 `CloseDocumentGroup` 外，`CloseDocuments` 对指定文档共同完成关闭确认，再只关闭这些文档并保留共享窗口。不得用逐个确认后逐个关闭代替，以免中途取消已留下半关闭状态。

## 取舍

一个窗口中的多个根目录消除了跨文件夹文档切换的窗口管理成本，同时保留每个根目录独立、清晰的文件树和过滤状态。代价是宿主需要区分“窗口当前选择的根目录”和“窗口全部打开文档”，并确保后台索引事件不覆盖当前左栏。

未选择全根目录混合文件树：它会把大量文件和重复路径混入一个列表，也需要新的分组层级。未选择顶部 Workspace Switcher 或第二层 Tab：现有 Workspace 名称与文档标签已经足够承载这两个不同概念。

本决策继续遵守单一文档权威、字节保真、恢复副本、外部冲突和关闭保护。三栏职责、正文排版、编辑器、GenUI 与设置存储不变。

## 框架约束

MyGo v0.7.4 的受控文档组补丁继续负责一个原生窗口的有序文档与活动文档。应用宿主在其上保存多个根目录及各自索引；`byWindow` 指向当前导航根目录，`byWorkspace` 保存窗口的全部根目录。根目录间移动文档仍使用 `Documents.Attach`，身份不变。

空根目录选中时，宿主清除 MyGo 的活动文档，窗口标题显示根目录名，File 菜单的文档命令禁用。其他根目录的文档仍保留在组中。后台文档状态更新时，窗口快照仍以 `byWindow` 指向的根目录为准。
