# ADR 0005：工作区、文档标签与窗口归属

- 状态：已采纳（文档／窗口模型已确认；与其余界面改动统一进入后续规格和任务拆分）。
- 日期：2026-11-08
- 补充：ADR 0001 的多窗口／标签页模型未决项，以及 ADR 0004 的工作区导航职责。

当前实现是一份原文一个原生窗口，设计稿要求在工作区窗口顶部用文档标签切换原文。窗口归属、同一原文的编辑会话唯一性和重启恢复会共同影响保存、冲突保护与文档生命周期，不能仅靠增加标签样式解决。

## 已确认的产品决策

1. **一个工作区对应一个文件夹、一个窗口。** 工作区内的多份原文在同一窗口的顶部文档标签栏切换。再次打开同一工作区时定位已有窗口。
2. **同一份磁盘文件全应用只保留一个打开的编辑会话。** 从 Finder、菜单或文件树重复打开时定位已有文档标签，不产生第二份待保存内容。
3. **重启恢复上次会话。** 恢复上次未主动关闭的工作区、文档标签、活动原文和各自视图模式，保留现有未保存内容恢复能力。
4. **打开文件优先复用已有工作区。** 先定位已有文档标签；没有已打开标签时，进入包含该文件的已打开工作区，多个根目录包含它时选择根目录最深的工作区。没有匹配工作区时，以文件父目录打开工作区。
5. **关闭最后一个文档标签保留工作区窗口。** 左栏文件树仍可使用，中央回到空状态。`⌘W` 关闭当前文档标签；窗口关闭按钮关闭整个工作区，并继续执行保存与冲突保护。
6. **切换文档标签不取消生成。** GenUI 任务、进度、结果与撤回归发起它的原文，允许在后台继续运行；关闭该原文标签或退出其工作区时取消任务。
7. **无工作区时可以先写未命名原文。** 使用尚未绑定文件夹的临时窗口，首次保存后确定原文的工作区归属；临时原文也有未保存内容恢复保护。
8. **另存到工作区外时迁移标签。** 保存成功后，按文件打开路由把标签迁入包含目标文件的已有工作区；没有匹配时使用目标父目录，保持已保存原文与窗口根目录归属一致。
9. **允许同一工作区多份原文并发生成。** 每份原文最多一个任务；任务的进度、取消、结果和撤回各自隔离，不同原文之间不互相阻塞。
10. **保留 MyGo 文档内核并做最小扩展。** 复用现有保存、恢复和冲突能力，补齐同窗多文档归属、活动文档菜单与保存对话框路由。接受维护受控依赖补丁的成本，并以真实原生流程验证。
11. **临时窗口中的原文独立确定归属。** 首次保存 A 只迁移 A 的标签，其余未命名原文留在临时窗口。临时窗口没有标签时关闭；已绑定文件夹的工作区窗口仍按第 5 项保留。
12. **生成中暂缓改变该原文路径。** 禁用该原文的另存为、改名和移动，提示先取消生成或等待结束；普通保存、继续编辑与标签切换可用，其他原文不受影响。

## 取舍

按文件夹划分窗口，保留独立的文件导航与阅读上下文，代价是需要管理多个工作区窗口。未选择全应用只有一个切换工作区的窗口，也未选择同窗多个根文件夹。

同一原文只保留一个编辑会话，避免多个窗口出现各自待保存的文本；暂不提供同一原文的多个同步编辑视图。恢复上次会话需要持久化工作现场，用户接受这一成本以延续退出前的工作。

本决策保留 ADR 0001 的单一文档权威与字节保真要求，不改变保存、恢复副本、外部冲突和关闭保护的可靠性要求。

## 框架约束

项目使用的 MyGo v0.7.4 将文档生命周期绑定到窗口；只读核对的 v0.8.3 [文档契约](https://raw.githubusercontent.com/egoist/mygo/v0.8.3/docs/documents.md)仍明确为“一文档一窗口”。升级本身不能提供同窗多文档。

把同一窗口返回给多个文档会覆盖现有框架的窗口到文档映射；隐藏文档窗口仍受原生焦点、菜单和保存对话框归属影响。选定的方向是为 MyGo 正式补齐多文档承载能力，不依靠映射覆盖或隐藏文档窗口绕开现有模型。
